# Calculator

## Objective
A simple calculator built in Java using _Scanner_ for user input and basic arithmetic operations.

---

## Features
- Addition
- Subtraction
- Multiplication
- Division (with zero-check validation)  
- Continuous operation until user exits

---

## Tools Used
- Java programming language
- VS Code/IntelliJ IDEA
- Output in Terminal

---

## How to Run
Compile and run the program
To Compile: javac calculator.java
Run the program: java calculator

---

## Program Flow
1. User selects an operation from the menu.  
2. Program takes two numeric inputs.  
3. Performs the selected operation.  
4. Displays the result.  
5. Continues until the user selects Exit.

---

## Example Output

**Calculator**
1. Addition | 2. Subtraction | 3. Multiplication | 4. Division | 5. Exit
Enter your choice: 1
Enter first number: 12
Enter second number: 8

---

## Highlights
- Handles invalid choices and division by zero.  
- Simple and user-friendly console interface.
